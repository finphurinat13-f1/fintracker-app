# FinTracker

เครื่องมือติดตามการเงินและพอร์ตลงทุนส่วนตัว — หุ้น คริปโต ทองคำ เงินสด และหนี้สิน อยู่ในที่เดียวกัน

สร้างด้วย React + Firebase โดยกำกับทิศทางผ่าน Claude Code ทั้งหมด ผู้เขียนไม่ได้พิมพ์โค้ดเอง

## บัญชีและข้อมูล

สมัครด้วยอีเมลจริง ยืนยันอีเมล แล้วรอผู้ดูแลอนุมัติ

ข้อมูลเก็บบน Firebase Firestore ซิงค์ข้ามคอมและมือถือได้

**รหัสผ่านของคุณ ผู้พัฒนาไม่เห็น** — Firebase เก็บไว้เป็นค่าแฮช ลืมแล้วรีเซ็ตทางอีเมลได้ ข้อมูลไม่หาย

`firestore.rules` กันไม่ให้ผู้ใช้อ่านข้อมูลของกันและกัน และต้องยืนยันอีเมล + อนุมัติแล้วจึงเขียนข้อมูลได้

---

## ไฟล์สำรองข้อมูล

Export ใส่รหัสได้ ไฟล์ที่ได้เข้ารหัสจริงด้วย **AES-GCM 256 บิต** บนกุญแจที่ผ่าน **PBKDF2-SHA256 250,000 รอบ** ผ่าน Web Crypto API ของเบราว์เซอร์ — โค้ดอยู่ใน `fintracker/src/lib.js` ที่ `encryptBackup`

รหัสของไฟล์ไม่ถูกเก็บไว้ที่ไหนเลย **ลืมแล้วเปิดไฟล์นั้นไม่ได้อีกตลอดไป** ไม่มีทางกู้

เปิดไฟล์นอกแอปได้ด้วย `node tests/backup-crypto.mjs decrypt <ไฟล์>`

---

## ล็อกหน้าจอ ≠ การเข้ารหัส

แอปมีระบบใส่รหัสก่อนดูยอดเงิน **มันซ่อนตัวเลขจากสายตาเท่านั้น** — ข้อมูลใน localStorage ยังเป็นข้อความเปล่า ใครเปิดเครื่องมือนักพัฒนาก็อ่านได้

เขียนไว้ตรงนี้เหมือนที่เขียนไว้ในแอป เพราะฟีเจอร์ความปลอดภัยที่ทำให้เข้าใจผิดว่าปลอดภัย อันตรายกว่าไม่มีเลย

## รันเอง

```bash
npm install
npm run check     # lint → test → audit → build
npm run build     # สร้าง fintracker/dist
```

ถ้าจะรันเอง ต้องสร้างโปรเจกต์ Firebase ของตัวเองแล้วแก้ config ใน `fintracker/index.html` และ `ADMIN_EMAIL` ใน `fintracker/src/app.jsx`, `functions/index.js`, `firestore.rules`

*(ค่า Firebase config ในหน้าเว็บไม่ใช่ความลับ — เป็นค่าที่ออกแบบมาให้เปิดเผยได้ ความปลอดภัยมาจาก `firestore.rules` และการตรวจสิทธิ์ใน `functions/index.js`)*

## การทดสอบ

```bash
npm test          # 70 การทดสอบ เน้นสูตรคำนวณเงินโดยเฉพาะ
npm run audit     # ตรวจไฟล์ backup ว่ามีสภาพที่เป็นไปไม่ได้ไหม
```

เกือบทุกการทดสอบมาจากบั๊กที่เคยเกิดขึ้นจริง เก็บไว้เพื่อไม่ให้กลับมา

## โครงสร้าง

```
fintracker/src/app.jsx    ทั้งแอป (React, JSX)
fintracker/src/lib.js     สูตรคำนวณเงิน — ไม่มี React ไม่มี DOM จึงทดสอบได้
functions/index.js        ดึงราคาหุ้น/คริปโต (ต้องล็อกอิน + ได้รับอนุมัติ)
tests/                    การทดสอบสูตรเงิน + สคริปต์ตรวจข้อมูล
build/                    esbuild + tailwind
```
